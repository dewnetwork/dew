# `0x101` Native Limit Orderbook Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the `0x101` native limit orderbook precompile (place / cancel / fill-by-id + views) behind `EnableNativeSwap` (default **off**), with hardfork documentation for the reserved→flagged transition under `public-testnet-v1`.

**Architecture:** Mirror staking (`0x102`): storage module in `core/native/orderbook.go` under account `0x101`; method-byte precompile in `core/vm/precompiles.go` (or split `orderbook_precompile.go`); register with `LiveInMap: true` + `SlotFlagged`; gate methods with `EnableNativeSwap`. DEW quote via CALLVALUE; base ERC-20 via nested `EVM.Call` `transferFrom` / `transfer`. v1 is fill-by-`orderId` only (no auto-walk).

**Tech Stack:** Go, `core/native`, `core/vm`, `params`, existing `TokenCreationBytecode` (extend with approve/transferFrom), node flag / `dew run --native-swap`.

**Spec:** [2026-07-15-0x101-orderbook-design.md](../specs/2026-07-15-0x101-orderbook-design.md)

## Locked implementation decisions (resolve design open points)

| Point | Lock for this PR |
| :--- | :--- |
| Base ERC-20 custody | **`transferFrom` / `transfer` via nested `EVM.Call`** from the precompile (pass `*ethvm.EVM` into the precompile struct, same pattern as holding `statedb`). Not two-step CreditBase — uncredited `transfer` to shared `0x101` is stealable across txs. |
| `CreditBase` `0x07` | **Omit from v1** (not needed with transferFrom). Keep method byte free; unknown method reverts `"method"`. Document omission in hardfork + precompiles.md. |
| Quote DEW | CALLVALUE only (EVM transfers value to `0x101` before `Run`). |
| Rounding | `quote = (base * priceX18) / 1e18` **floor**. **Sell fill:** maker receives floor quote (taker slight improvement). **Buy place lock:** `quoteLock = ceil(base * priceX18 / 1e18) = (base * priceX18 + 1e18 - 1) / 1e18` so full size is coverable. **Buy fill:** quote paid to taker = floor. Dust stays in module / order escrow accounting. |
| Gas (initial constants) | Place 50_000 · Cancel 30_000 · Fill 80_000 · Views 3_000 · ERC-20 nested call gas charged from call stipend inside `RequiredGas` pad (Fill/Place sell include headroom). |
| Limits | Max **64** open orders per maker; reject Place beyond cap. Max fills/tx = **1** (single Fill method); design’s 16 is for future MatchBest. |
| BestBid/Ask | Maintain open-id list per `(baseToken, side)`; recompute best on Place/Cancel/Fill (O(n) open on that side). |
| Actor | **tx.origin** (`msg.From` / `evm.TxContext.Origin`) for place/cancel/fill auth (same fail-closed note as staking zero-value methods). Payable buy Place credits the value-payer via Transfer hook if nested; document like staking. |
| Activation | Hardfork doc + `LiveInMap: true` + `EnableNativeSwap` default **false**. Public operators keep flag off until policy says otherwise. |
| Allowlist | **No** baseToken allowlist in v1. |

```text
OrderbookModuleAddr = 0x…0101

Storage domains (keccak parts, same style as staking):
  dew/ob/v1/nextId
  dew/ob/v1/order/{id8}          → packed fields across slots (see below)
  dew/ob/v1/openCount/{maker}
  dew/ob/v1/escrowQ/{maker}
  dew/ob/v1/escrowB/{maker}/{token}
  dew/ob/v1/openLen/{token}/{side}
  dew/ob/v1/openAt/{token}/{side}/{idx8} → orderId u64
```

**Order status:** `0 open · 1 filled · 2 cancelled`

**Order pack (slots under `order/{id}`):**

| Slot suffix | Content |
| :--- | :--- |
| `/hdr` | maker(20) \|\| side(1) \|\| status(1) \|\| createdAt(8) in 32-byte right/left layout — use fixed offsets documented in code |
| `/token` | baseToken address right-aligned |
| `/price` | priceX18 |
| `/open` | baseOpen |
| `/orig` | baseOrig |

**API:**

```go
func QuoteFloor(base, priceX18 *uint256.Int) *uint256.Int  // base*price/1e18
func QuoteLockCeil(base, priceX18 *uint256.Int) *uint256.Int

func (m *OrderbookModule) PlaceBuy(maker, token crypto.Address, price, baseAmt *uint256.Int, blockNum uint64) (id uint64, quoteLock *uint256.Int, err error)
func (m *OrderbookModule) PlaceSell(...) (id uint64, err error)
func (m *OrderbookModule) Cancel(actor crypto.Address, id uint64) (Refund, error) // only maker
func (m *OrderbookModule) Fill(taker crypto.Address, id uint64, maxBase *uint256.Int) (baseFilled, quotePaid *uint256.Int, err error)
func (m *OrderbookModule) GetOrder(id uint64) (Order, bool)
func (m *OrderbookModule) BestBid/BestAsk(token) (price *uint256.Int, id uint64, ok bool)
func (m *OrderbookModule) EscrowQuote/EscrowBase(...)
func (m *OrderbookModule) OpenCount(maker) uint64
```

**Fill rules:** order open; `maxBase` clamped to `baseOpen`; any taker may fill (no self-trade ban required in v1 — optional reject `taker==maker`); quote via `QuoteFloor`; reduce baseOpen; if zero → filled; adjust escrow maps (sell: decrease maker escrowBase; buy: decrease maker escrowQuote). Open-index remove on full fill/cancel; recompute not needed if index accurate — Best walks open list.

**PlaceBuy:** does **not** move DEW balances (precompile does); only updates escrowQuote accounting after precompile verified CALLVALUE ≥ quoteLock (precompile passes actual lock). Module `PlaceBuy` increases `escrowQuote[maker]` by `quoteLock`.

**PlaceSell:** module increases `escrowBase[maker][token]` by `baseAmt` after precompile pulled tokens.

**Cancel refund:** returns `{Quote, Base}` amounts for precompile to transfer out; clears escrow accounting.

```solidity
pragma solidity ^0.8.24;
contract Token {
  mapping(address => uint256) public balanceOf;
  mapping(address => mapping(address => uint256)) public allowance;
  event Transfer(address indexed from, address indexed to, uint256 value);
  event Approval(address indexed owner, address indexed spender, uint256 value);
  constructor(uint256 supply) {
    balanceOf[msg.sender] = supply;
    emit Transfer(address(0), msg.sender, supply);
  }
  function transfer(address to, uint256 amount) external returns (bool) {
    _transfer(msg.sender, to, amount);
    return true;
  }
  function approve(address spender, uint256 amount) external returns (bool) {
    allowance[msg.sender][spender] = amount;
    emit Approval(msg.sender, spender, amount);
    return true;
  }
  function transferFrom(address from, address to, uint256 amount) external returns (bool) {
    uint256 a = allowance[from][msg.sender];
    require(a >= amount, "allowance");
    if (a != type(uint256).max) allowance[from][msg.sender] = a - amount;
    _transfer(from, to, amount);
    return true;
  }
  function _transfer(address from, address to, uint256 amount) internal {
    require(balanceOf[from] >= amount, "balance");
    balanceOf[from] -= amount;
    balanceOf[to] += amount;
    emit Transfer(from, to, amount);
  }
}
```

```go
// core/vm/orderbook_precompile.go
const (
	ObMethodPlace    byte = 0x00 // side u8 || token 20 || price 32 || base 32
	ObMethodCancel   byte = 0x01 // orderId 32
	ObMethodFill     byte = 0x02 // orderId 32 || baseAmount 32
	ObMethodGetOrder byte = 0x03 // orderId 32
	ObMethodBestBid  byte = 0x04 // token 20
	ObMethodBestAsk  byte = 0x05 // token 20
	ObMethodGetEscrow byte = 0x06 // maker 20 || token 20
)

type orderbookPrecompile struct {
	statedb *state.StateDB
	self    crypto.Address
	origin  crypto.Address
	evm     *ethvm.EVM // for ERC-20 Call
	valueCtx *stakeValueCtx // reuse or parallel obValueCtx for value into 0x101
	blockNum uint64
	enabled bool
}
```

**RequiredGas:** switch on method byte → `params.OrderbookGas*`.

**Run:**

1. If `!enabled` → `fmt.Errorf("native swap: not enabled (set EnableNativeSwap)")`.
2. Switch methods; malformed length → revert error (no panic).
3. Unknown method → `fmt.Errorf("method")` or `"native swap: unknown method"`.

**Place buy (`side=0`):** parse fields; `quoteLock := native.QuoteLockCeil(...)`; require valueCtx amount ≥ quoteLock (or exact — **lock exact: CALLVALUE must equal quoteLock** to avoid stranded dust on precompile); call `mod.PlaceBuy`; consume valueCtx.

**Place sell (`side=1`):** CALLVALUE must be 0; `transferFrom(origin, self, baseAmount)` via ERC-20 helper; `mod.PlaceSell`.

**Cancel:** `mod.Cancel(origin, id)`; if quote refund > 0, SubBalance self / AddBalance origin; if base refund > 0, `transfer(origin, base)`.

**Fill sell order (maker side sell):** taker pays CALLVALUE ≥ quote; pull exact quote to stay at self (already transferred by EVM); `mod.Fill`; `transfer` base to taker; refund excess CALLVALUE if any **or require exact** — **lock exact quotePaid** (compute first? chicken-egg). Pattern: Fill computes quote from maxBase; require CALLVALUE ≥ quotePaid; refund excess DEW to taker after fill.

**Fill buy order:** CALLVALUE 0; `transferFrom` base from taker; `mod.Fill`; SubBalance quote to taker.

**GetOrder:** pack fixed output: id\|maker\|token\|side\|price\|baseOpen\|baseOrig\|createdAt\|status (document lengths) or empty 0 bytes if missing.

**BestBid/Ask:** price32 \| orderId32; zeros if none.

**GetEscrow:** base32 \| quote32.

```go
func u256Pad32(v *uint256.Int) []byte {
	return append(make([]byte, 0, 32), leftPad32(v.ToBig().Bytes())...)
}

func leftPad32(b []byte) []byte {
	out := make([]byte, 32)
	copy(out[32-len(b):], b)
	return out
}

func packPlace(side byte, token crypto.Address, price, base *uint256.Int) []byte {
	out := make([]byte, 0, 1+1+20+32+32)
	out = append(out, ObMethodPlace, side)
	out = append(out, token[:]...)
	out = append(out, u256Pad32(price)...)
	out = append(out, u256Pad32(base)...)
	return out
}

func TestOrderbook_PlaceBuyCancel_Refund(t *testing.T) {
	exec, statedb, maker, _, token, ob := setupOrderbook(t)
	price := uint256.NewInt(2e18)
	base := uint256.NewInt(1e18)
	// quoteLock ceil = 2e18
	lock := uint256.NewInt(2e18)
	before := new(uint256.Int).Set(statedb.GetBalance(maker))
	res, err := exec.ApplyMessage(Message{
		From: maker, To: &ob, Value: lock,
		GasLimit: 200_000, GasPrice: big.NewInt(0),
		Data: packPlace(0, token, price, base),
	})
	if err != nil || res.Failed {
		t.Fatalf("place buy: %v %v", err, res.Err)
	}
	orderID := new(uint256.Int).SetBytes(res.ReturnData)
	if orderID.Uint64() != 1 {
		t.Fatalf("id %s", orderID)
	}
	// cancel
	cancel := append([]byte{ObMethodCancel}, u256Pad32(orderID)...)
	res, err = exec.ApplyMessage(Message{
		From: maker, To: &ob, Value: uint256.NewInt(0),
		GasLimit: 100_000, GasPrice: big.NewInt(0), Data: cancel,
	})
	if err != nil || res.Failed {
		t.Fatalf("cancel: %v %v", err, res.Err)
	}
	// gas burned with GasPrice=0 → balance restored by refund lock
	if statedb.GetBalance(maker).Cmp(before) != 0 {
		t.Fatalf("maker balance after cancel want %s got %s", before, statedb.GetBalance(maker))
	}
}

func TestOrderbook_PlaceSellFill_WithERC20(t *testing.T) {
	exec, statedb, maker, taker, token, ob := setupOrderbook(t)
	price := uint256.NewInt(1e18)
	baseAmt := uint256.NewInt(10)

	// approve(ob, 10)
	approveSel, _ := hex.DecodeString("095ea7b3")
	approveData := append(approveSel, leftPad32(ob[:])...)
	approveData = append(approveData, u256Pad32(baseAmt)...)
	res, err := exec.ApplyMessage(Message{
		From: maker, To: &token, Value: uint256.NewInt(0),
		GasLimit: 100_000, GasPrice: big.NewInt(0), Data: approveData,
	})
	if err != nil || res.Failed {
		t.Fatalf("approve: %v %v", err, res.Err)
	}

	res, err = exec.ApplyMessage(Message{
		From: maker, To: &ob, Value: uint256.NewInt(0),
		GasLimit: 300_000, GasPrice: big.NewInt(0),
		Data: packPlace(1, token, price, baseAmt),
	})
	if err != nil || res.Failed {
		t.Fatalf("place sell: %v %v", err, res.Err)
	}
	orderID := new(uint256.Int).SetBytes(res.ReturnData)

	// taker fill 4 base, pay 4 wei quote
	fill := append([]byte{ObMethodFill}, u256Pad32(orderID)...)
	fill = append(fill, u256Pad32(uint256.NewInt(4))...)
	takerTokBefore := tokenBalance(t, exec, statedb, token, taker)
	res, err = exec.ApplyMessage(Message{
		From: taker, To: &ob, Value: uint256.NewInt(4),
		GasLimit: 400_000, GasPrice: big.NewInt(0), Data: fill,
	})
	if err != nil || res.Failed {
		t.Fatalf("fill: %v %v", err, res.Err)
	}
	if tokenBalance(t, exec, statedb, token, taker).Uint64() != takerTokBefore.Uint64()+4 {
		t.Fatal("taker did not receive base")
	}
}
```
