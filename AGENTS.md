# Development Rules

- Development documentation is located in the [docs/](docs/) folder.
- Always record technical debt in [agents/debt.md](agents/debt.md).
- Always check [agents/debt.md](agents/debt.md) before starting a task; if there is any debt item suitable to address within the scope of the current task, proactively ask the user.
- Always ask the user for feedback/approval regarding architectural decisions or any choices that deviate from the existing documentation in the [docs/](docs/) folder.
- Do not use absolute paths in the documentation files inside the [docs/](docs/) folder; always use relative paths.
- Always keep the codebase and the documentation in the [docs/](docs/) folder synchronized (ensure documentation is updated when implementing or modifying features).
